# Ejercicios HTML5 y CSS3

Colección de ejercicios y prácticas desarrollados durante mi formación
en desarrollo web frontend. Incluye maquetaciones, layouts y componentes
construidos con HTML5 semántico y CSS3.

## 🛠️ Tecnologías

- HTML5 semántico
- CSS3 (Flexbox, Grid, variables CSS)
- Diseño responsive

## 📁 Contenido

- Maquetaciones de páginas completas
- Componentes reutilizables (cards, navbars, formularios)
- Layouts con Flexbox y Grid
- Ejercicios de responsive design

## 🎯 Objetivo

Repositorio de práctica y referencia personal para consolidar
los fundamentos de HTML y CSS antes de escalar a JavaScript y frameworks.

## ▶️ Cómo verlo

1. Clona el repositorio:
```bash
   git clone https://github.com/edvillamizar/HTML_CSS.git
```
2. Abre cualquier archivo `.html` directamente en tu navegador
